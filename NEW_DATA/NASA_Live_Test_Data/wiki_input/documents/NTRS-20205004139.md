## Abstract

The purpose of this test was to validate the Intersil HSYE-117RH-Q flight lot for use in the fabrication of Europa Clipper Propulsion subsystem flight hardware.  This test shall serve as the radiation lot acceptance test (RLAT) for the flight lot date with wafer lot number G3X3CQC and lot date code (LDC) 1830. Low dose rate (LDR) irradiations have been performed by the manufacturer, but only to 100 krad(Si). This test was a follow-on to the original Radiation Lot-Specific Acceptance Testing (RLAT) performed on this LDC. Application-specific load currents were used for the line regulation and load regulation measurements. All other parameters were measured with standard bias conditions as specified in the datasheet.
