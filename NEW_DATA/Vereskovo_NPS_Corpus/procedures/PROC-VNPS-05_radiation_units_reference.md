# Radiation and engineering units reference - VNPS-1

FICTIONAL TRAINING PROCEDURE - written for testing the FRIB decision-support system with the fictional Vereskovo NPS records. Not a real or FRIB operating procedure.

Version: VNPS-1 (2026-11-17)

## Purpose
Convert the 1980s units used in the records.

| From | To | Conversion |
|---|---|---|
| rem | sievert (Sv) | 1 rem = 0.01 Sv |
| rad | gray (Gy) | 1 rad = 0.01 Gy |
| roentgen (R), gamma | rem | about 1 R = 1 rem (0.96 in soft tissue) |
| micro-roentgen per second (uR/s) | mR/h | 1 uR/s = 3.6 mR/h |
| curie (Ci) | becquerel (Bq) | 1 Ci = 3.7 x 10^10 Bq |
| Ci/km2 | kBq/m2 | 1 Ci/km2 = 37 kBq/m2 |
| Ci/L | Bq/L | 1 Ci/L = 3.7 x 10^10 Bq/L |
| MCi/day | Bq/day | 1 MCi = 3.7 x 10^16 Bq |
| kgf/cm2 | MPa | 1 kgf/cm2 = 0.0981 MPa |

The station's own reference card: [DOC-1987-0003 - Training center reference card: units and limits (for retraining of personnel)](../corpus/DOC-1987-0003_training-card.md).
