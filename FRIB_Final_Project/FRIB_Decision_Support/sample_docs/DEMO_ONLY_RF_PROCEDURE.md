# DEMO ONLY — Fictional RF Trip Review Procedure

**Not an FRIB procedure. Not for operational use.** This document exists only to exercise the local RAG pipeline.

## 1 Event review
When reviewing the fictional RF trip scenario used in this repository, compare the synthetic cavity-field, forward-power, reflected-power, and tuner-pressure traces around the recorded synthetic interlock time.

## 2 Evidence handling
Preserve the original synthetic event record. Derived plots and calculated features should be stored separately from the raw synthetic evidence. Any causal statement remains a hypothesis until a human reviewer approves or corrects it.

## 3 Escalation
If the available synthetic evidence and this demo document do not support a conclusion, mark the draft for escalation rather than inventing an operating action.
