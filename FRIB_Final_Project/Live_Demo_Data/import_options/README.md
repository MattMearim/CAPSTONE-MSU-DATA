# Import mapping reference

Each JSON sidecar records the matching dataset's intended mapping, quality expectations and expected results. These files are reference material, not datasets or procedure uploads. Test Lab already supplies these settings. General Data workspace uploads require you to enter any desired mappings/expectations explicitly. The REPAIR sidecar describes a reviewed repair under `expected.repair_options`; the raw default import remains blocked. Native mechanical JSON uses event import and has no mixed-data mapping.
