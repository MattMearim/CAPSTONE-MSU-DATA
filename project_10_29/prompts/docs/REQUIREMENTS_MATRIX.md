# Requirements coverage and deployment boundary

Reviewed against the supplied capstone brief, the four-level RF/SRF architecture figure, and the MOPO074 paper. Documents are reference material; their operational descriptions do not authorize equipment actions.

| Requirement | Implemented behavior | Validation / boundary |
|---|---|---|
| Non-autonomous, human-supervised layer | No equipment control endpoints; named human Approve/Correct/Escalate gate | Duplicate/concurrent review transaction prevention; escalation never publishes |
| Level 1: original evidence and provenance | Immutable canonical event JSON, original CSV/JSON imports, logs/screenshots/PDF attachments, SHA-256, source timestamp and optional cavity/cryomodule/mode/beam/configuration metadata | Downloaded originals match uploads; duplicate event IDs rejected; attachment deletion leaves event JSON unchanged |
| RF/SRF operational data sources | JSON/CSV ingestion and evidence attachment APIs provide an adapter boundary | Live EPICS, archived RF, cryogenic and LLRF/elog integrations require facility access and approved adapters; files alone are not live acquisition |
| Scriptable synthetic engineering generator | RF trip, mechanical vibration and PLC interlock; configurable scenarios, seeded signals and portable JSON CLI | Reproducible generated signals; bounded finite parameters; generator does not initialize AI services |
| Standard contracts and modular processing | Pydantic validation, regenerated JSON Schemas/OpenAPI, generator/processor/provider interfaces | Finite values, increasing time axes, consistent lengths, safe IDs; import errors explain the violated contract |
| Mixed numeric and nonnumeric ingestion | CSV role mapping, categorical/boolean changes, text logs, TXT/MD/LOG/text-PDF extraction, deterministic summaries and recorded quotes | Preview without writes, exact originals, missing timing labeled record order; prose never becomes an invented physical measurement |
| Uniform units | Deterministic registry, per-cell/per-row source units, canonical SI storage and standardized exports, conversion provenance | Scale/offset/prefix/dimension tests, absolute versus differential temperatures; unsupported new declarations rejected and legacy unknown units flagged |
| Dynamic labeled interface | Editable plot titles/labels, separate measurement axes with units, channel/window/category/severity filters, live ingestion preview and explicit save | Component tests plus real parser/API walkthrough; large previews bounded while all source rows remain validated |
| L1/L2 quality review and proposed fixes | Full-file source checks, unit suggestions, explicit derived-copy repairs, recording-gap and value-behavior checks, configurable bounds/cadence/stability | Bounded row/time evidence, unchanged originals, repair receipts; anomaly warnings can describe real events and do not establish negligence |
| Level 2: cleaning, alignment and visualization | Audited cleaning helpers, common capture overlap, timestamp-derived uniform grids, per-channel units, FFT spectra, timelines, warnings, JSON/CSV exports | Known sine-wave frequency/amplitude, unequal time grids, short captures, chronological states; raw events remain unchanged |
| RF trip analysis | Pre/post waveform products, observed 1/e field threshold, tuner-pressure changes, forward/reflected comparisons and interlock timing | Synthetic timing and analytic decay checks; threshold estimate is not a commissioned cavity parameter |
| Field-emission analysis | Optional X-ray/gradient channel trends, descriptive correlation and scatter plots, event timeline | Validates numeric products; repeated scan comparison and conditioning-effect diagnosis remain sponsor physics/data work |
| Level 3: approved-document retrieval | PDF/TXT/MD originals, versions, chunks, page/section references; unapproved originals excluded; persistent SQLite or hydrated memory index | Upload/restart/delete tests; unavailable model or invalid citations never marked as a successfully grounded AI answer |
| Evidence / procedure / interpretation separation | Distinct display sections, retrieval modes, source IDs/version/page, deterministic demo excerpts, tentative model interpretation | UI tests verify labels; citation presence is checked, semantic factual support still needs expert evaluation |
| Level 4: draft generation and evidence ordering | Event summary, measured observations, tentative RF/mechanical/PLC observation-pattern candidates, suggested review steps, hardware, tags and evidence snapshot | Default demo ranks candidates by available supporting observations, then contradictions, with stable template order; three-domain integration checks preserve findings and exclude synthetic labels. This is not validated causal diagnosis or statistical confidence; local-model ordering remains unvalidated |
| Human review and reusable knowledge | Editable corrections, explicit reviewer/acknowledgement, atomic publication, persistent draft status, reviewed wiki/search/reports | Approve and Correct publish; Escalate does not; original/corrected drafts retained in audit; repeated stale approval rejected |
| Add/delete/download files | Multiple reference uploads, evidence attachments, per-file confirmation, dataset delete cascade, immutable original bytes | Deletion removes retrieval and stays effective after restart; audit history and prior report source snapshots remain historical |
| Three engineering domains | RF/SRF, mechanical and PLC generators/processors plus end-to-end application flow | Domain tests and isolated API/UI tests; sponsor must evaluate representativeness of synthetic signals |
| Easy local startup | Windows launcher, verified private Python bootstrap when missing, required version/import/dependency checks, staged repairs, both services, readiness checks and logs | Clean-copy first setup, warm offline check, startup locks, interruption/recovery and actual Windows launch/browser verification |
| System information and upgrades | Hardware/resource inventory, component versions/purposes, explicit PyPI metadata check, individual or complete package update plans, optional semantic choice, private runtime updates and plan cancellation | Allowlisted plans validated again at startup; replacement environment activates only after checks; saved application data and existing environments are preserved. Hardware suitability is an estimate; ARM64 and real model performance need host validation |
| Docker and deployment | Lightweight default Compose, optional Ollama profile, shared persistent data, backend health check | Configuration provided; Docker engine unavailable in this environment, build/run not verified |
| Validation and reporting | Automated tests, reproducible demo steps, this matrix and validation report | Test results report software behavior, not facility commissioning or model accuracy |

## Inputs still needed before facility use

Official approved procedures; read-only facility connectors; representative RF/SRF and field-emission datasets; calibrated units; sponsor-approved synthetic physics and numerical tolerances; domain hypothesis rules; expert evaluation of model faithfulness and retrieval quality; authentication/authorization; retention/backup policy; and host-specific deployment testing.

Linear interpolation does not recover missing bandwidth. Irregular gaps reduce spectral reliability. Explicit downsampling by an adapter has no anti-alias filter and emits a warning. The default overlay grid uses the fastest measured channel; FFT uses its primary channel's own measured sampling rate.

The project does not claim statistical hypothesis confidence, autonomous diagnosis, autonomous corrective actions, or validated operating guidance.
